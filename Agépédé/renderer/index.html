Environnement : détection…

Une ligne par unité d'organisation. OU parente : vide = racine du domaine, sinon le chemin de l'OU parente, par exemple Paris/Compta.

Comptes utilisateurs (le A de AGDLP). Identifiant : nom d'ouverture de session (20 caractères max.), ex. jdupont. Ajoutez ensuite chaque compte dans un groupe global (onglet GG, colonne Membres). Les mots de passe apparaissent en clair dans le script.

Groupes globaux (le G de AGDLP) : ils regroupent les comptes utilisateurs (A). Membres : noms d'ouverture de session (sAMAccountName) séparés par des virgules, par exemple jdupont, mmartin.

Groupes domaine local (le DL de AGDLP) : ils reçoivent les permissions. Membres : groupes globaux séparés par des virgules.

Créer les DL pour un GG : Ajoute deux groupes domaine local (lecture, modification) contenant ce groupe global, dans la même OU.

Dossiers à créer sur le serveur de fichiers (chemin local ou UNC, ex. D:\Partages\Compta). Cliquez sur le bouton Héritage d'une ligne pour casser l'héritage des autorisations : le dossier ne reprend plus les droits de son parent, seuls ses propres droits (onglet Permissions) s'appliquent.

Permissions NTFS (le P de AGDLP) : le groupe domaine local reçoit le droit sur le dossier (icacls, hérité par les sous-dossiers et fichiers). Chemin local du serveur de fichiers ou UNC, par exemple D:\Partages\Compta.
